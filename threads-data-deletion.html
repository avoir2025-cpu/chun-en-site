Cainergy Data Deletion

資料刪除說明

已連結 Threads 帳號的使用者If You Connected Your Threads Account

  • 在 Cainergy 裡按「取消連結」；或Click "Disconnect" in Cainergy; or
  • 到 Threads「設定 → 帳號 → 網站權限」，移除 Cainergy。In Threads, go to Settings → Account → Website permissions and remove Cainergy.

Threads 會通知我們，我們會自動刪除您的存取權杖、Threads 用戶編號與帳號名稱，並回給 Threads 一組確認碼。您可以用確認碼在本頁查詢刪除進度。

Threads notifies us, and we automatically delete your access token, Threads user ID and username, then return a confirmation code to Threads. You can use the code to check the status on this page.

被搜尋到的貼文作者If Our Search Found Your Post

請寫信到 contact@chunen.tw，附上貼文網址。我們會在收到後 30 天內刪除與該貼文相關的資料，並回信告知。

Email contact@chunen.tw with the post link. We will delete data related to that post within 30 days and let you know by email.
